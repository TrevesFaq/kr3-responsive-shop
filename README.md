## Исправления доступности

- На всех страницах добавлена ссылка «Перейти к основному содержимому» и цель `main`. Ссылка появляется при фокусе.
- Текущая страница отмечена через `aria-current="page"`. Убрано ошибочное выделение пункта «Популярные товары» на страницах товара и заявки, добавлен пункт «Заявка».
- Все интерактивные элементы получили видимую рамку фокуса. Для поля даты дополнительно используется `:focus-within`, чтобы рамка оставалась видимой при выборе частей даты.
- Исправлены alt-описания карточек, названия ссылок и кнопок уточняют номер товара.
- Обязательные поля отмечены звёздочкой и снабжены пояснением. Подсказка телефона связана с полем через `aria-describedby`.
- Ошибки формы показываются текстом рядом с полями и связаны с ними через `aria-describedby`. При ошибке фокус переходит к первому неверному полю. При редактировании устаревшая ошибка убирается.
- Модальное окно имеет заголовок, закрывается кнопкой и Escape. После закрытия фокус возвращается к кнопке заказа.
- В таблице добавлены заголовки строк `th scope="row"`; сохранены caption, заголовки столбцов и адаптивная прокрутка.
- Проверены основные цвета текста и фона. Для пользователей с настройкой уменьшения движения отключена плавная прокрутка.

Клавиатурные сценарии проверены в Edge на ширинах 360, 430, 768, 1024 и 1440px: ссылка пропуска, видимость фокуса, форма, открытие и закрытие окна, возврат фокуса и FAQ. Проверены подписи полей, ARIA-связи, уникальность id и отсутствие горизонтального переполнения всех пяти страниц.

## Адаптивные решения

- В `css/responsive.css` используется Mobile First: мобильная раскладка задаётся без медиазапросов, расширения — через `min-width`.
- Меню на телефоне вертикальное, с 768px — горизонтальное с переносом. Для меню и кнопок используется Flexbox.
- Grid-сетка карточек и отзывов перестраивается из одной колонки в две с 768px и три с 1024px.
- Фильтр каталога на телефоне находится над товарами, с 1024px — сбоку. В каталоге две колонки карточек с 1024px и три с 1200px.
- Hero и карточка товара имеют одну колонку на телефоне и две на desktop.
- Изображения ограничены шириной контейнера. Для карточек используются `srcset`, `sizes` и отложенная загрузка, для hero — `picture` с разными изображениями.
- Формы заявки и обратной связи имеют одну колонку на телефоне и две с 768px. Комментарий, согласие и кнопки занимают всю строку.
- Таблица прокручивается внутри `.table-wrapper`, сохраняя читаемый размер; вся страница не должна прокручиваться вбок.
- Модальное окно ограничено размерами экрана и имеет внутреннюю прокрутку.

## Постановка контрольной работы №4

Тема: «JavaScript: интерактивность, DOM, события, формы и валидация».

КР №4 выполняется позднее в отдельном репозитории `kr4-js-shop` на чистом JavaScript, без React и Vue. Основа — страницы предыдущих HTML/CSS-работ.

Обязательный функционал:

- открытие и закрытие модального окна;
- валидация формы и вывод ошибок;
- генерация карточек из массива объектов;
- поиск по каталогу;
- фильтрация по категории;
- сортировка по цене или названию;
- корзина со счётчиком и суммой;
- сохранение корзины или избранного в localStorage;
- отладка через Console и Breakpoint.

Планируемые файлы JS: `data.js`, `catalog.js`, `cart.js`, `modal.js`, `validation.js`, `main.js`. Дополнительно потребуются `cart.html` и `data/products.json`. Желательные расширения: fetch для products.json, избранное, тёмная тема, имитация отправки формы и пагинация.

На практической №14 фиксируется постановка КР №4; реализация этого функционала относится к следующим занятиям.
