# Контрольная работа №3 — Retro Shelf

**Тема:** «Адаптивная вёрстка и доступность многостраничного HTML/CSS-сайта».

Проект — адаптивная версия учебного магазина ретро-консолей. Он продолжает HTML/CSS-проект из КР №1. Bootstrap не используется.

## Страницы проекта

- `index.html` — главная страница, популярные товары и карусель.
- `catalog.html` — каталог с фильтром и карточками товаров.
- `product.html` — карточки товаров и таблицы характеристик.
- `order.html` — форма заявки.
- `contacts.html` — контактная информация.

## Практическая работа №12 — адаптивная вёрстка

- Добавлен отдельный файл `css/responsive.css`; он подключён после `css/style.css` на каждой странице.
- Для мобильного экрана используется одна колонка, для более широких экранов колонки добавляются через `min-width` медиазапросы.
- Адаптированы меню, hero-блок, каталог, карточки, форма и таблица характеристик.
- На широком экране фильтр каталога размещается сбоку, на узком — над товарами.
- Для изображения Sega Mega Drive подготовлены размеры 480, 640 и 960 пикселей; в каталоге используются `srcset` и `sizes`.
- Для изображений заданы `alt`, `width` и `height`; изображения каталога загружаются по мере прокрутки.

## Практическая работа №13 — доступность и Lighthouse

- Добавлена ссылка «Перейти к основному содержимому».
- На каждой странице есть основной заголовок `h1`; текущая страница в меню отмечена `aria-current="page"`.
- Добавлен заметный фокус клавиатуры для ссылок, кнопок и полей.
- Подписи формы связаны с полями; изображения товаров имеют осмысленные `alt`.
- Таблицы характеристик получили подписи, заголовки строк и контейнер с прокруткой на узком экране.
- У карусели есть кнопки переключения и остановки, а также подписи слайдов.

## Проверка адаптивности

После открытия проекта в браузере проверьте его на ширинах:

- 360px;
- 430px;
- 768px;
- 1024px;
- 1440px.

На этих ширинах проверьте все страницы, меню, карточки, форму, таблицу, изображения и отсутствие горизонтальной прокрутки всей страницы.
